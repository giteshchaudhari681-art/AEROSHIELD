# AEROSHIELD Domain Model Boundaries

The following logical domain entities define the boundaries of the AEROSHIELD intelligence pipeline:

- **Site:** Represents a protected infrastructure location (e.g., an airport or power plant).
- **Critical Asset:** Infrastructure within a site that must be protected (e.g., fuel tank, runway).
- **Restricted Zone:** Geographic security boundary with varying alert thresholds.
- **Sensor:** The source of telemetry (Radar, RF, EO/IR, Acoustic). Hardware agnostic.
- **Sensor Observation:** A single data point generated by a sensor at a given timestamp.
- **Drone / Aerial Track:** An observed aerial object tracked over time.
- **Behaviour Event:** A specific pattern detected by the behaviour engine (e.g., "hovering over asset").
- **Threat Assessment:** An evaluation of the risk/threat level posed by a track.
- **Alert:** An operator-facing security notification requiring attention.
- **Incident:** A collection of related alerts and events grouped over a period.
- **Evidence:** Supporting data (e.g., screenshots, signal strength) for a threat assessment.
- **Operator:** A human security user utilizing the dashboard to make decisions.
